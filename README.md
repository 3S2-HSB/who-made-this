# 🪐 Who Made This

> 슬랙 커스텀 이모지를 쉽고 빠르게 만들어주는 웹앱
> 
> 🏆 우아한테크코스 8기 테코톤 출품작 (2026)

## ✨ 주요 기능

- **텍스트 이모지** — 원하는 문구를 입력하면 폰트·색상·외곽선·애니메이션 효과까지 적용해 이모지로 변환
- **이미지 변환** — PNG/JPG 파일을 슬랙 이모지 규격(128×128px)으로 자동 변환
- **비디오 → GIF** — MP4 영상을 슬랙 등록 가능한 GIF(128KB 이하)로 자동 인코딩 및 압축
- **실시간 미리보기** — 슬랙 UI를 모사한 미리보기 창에서 실제 적용 모습 확인
- **원클릭 프리셋** — 파티 하이프, 네온 글리치, 골드 슈프림, 파스텔 웨이브 4종 즉시 적용

## 🛠 기술 스택

- **Gemini Canvas** (AI 기반 바이브 코딩)
- HTML / CSS / JavaScript
- Tailwind CSS
- [gifenc](https://github.com/mattdesl/gifenc) — GIF 인코딩

## 📖 사용 방법

1. 원하는 탭 선택 (텍스트 / 이미지 / 비디오)
2. 내용 입력 및 스타일 옵션 조정
3. 실시간 미리보기로 확인
4. **슬랙 최적화 이모지 다운로드** 클릭
5. 슬랙 워크스페이스 → 이모지 추가에서 등록
